# 当前预览包：目标机器验收清单

本清单合并旧测试版本中仍有效的要求。使用 `build/iMac-ReVoyage-Preview.zip`；安装、配对和卸载见 [快速上手](QuickStart-ZH.md)，已编译／实验支持范围见 [兼容性表](Compatibility.md)。以下均需用户安排实际机器测试，本轮清理不执行。

## 基准机器与安装

- Sender：M4 Mac mini；Receiver：iMac 21.5 Late 2015 非 Retina、1920×1080、macOS 10.15.7。记录 CPU／GPU、连接方式、协商速率和采集卡实际名称。
- 干净安装、登录启动、崩溃后独立恢复和升级回滚；Receiver 无需 Homebrew／Python，升级保留配对码及 UUID。
- 导入配对文件，确认错误设备／错误配对码无法连接。切换雷电／千兆有线接口或 IP 后重新选择设备，验证原配对、显示身份及排列沿用。
- 检查 Sender 录屏、输入控制权限门禁；观看画面无需输入控制权限。

## 显示、扬声器和性能

- 真实内屏识别为 1920×1080、1×；验证镜像、扩展、排列恢复和比例，避免把基准机报告为 5K／Retina。
- 固定 1080p60 H.264 建立基线，再验证自动模式持续吃力时降到 1080p30、稳定观察后的单次恢复；旧手动档位保持固定。
- 记录实际硬解／软解、丢帧、积压与恢复；比较空闲、网络拥塞和 CPU 负载下的画面新鲜度。接收端提交计数及最近提交时间不等于端到端延迟。
- 用同步画面／相机或光电方法测输入到显示时间。25–35 ms 是待验证目标，不能以平均 FPS 替代测量。
- 亮度命令作用于内屏，确认实际回读、失败反馈及连接不强制 100%；本地自动亮度设置保留。
- 验证音频方向、音画同步、静音和音频拥塞隔离；网络声音与 HDMI 声音不能叠加。

## HDMI Rescue 与人工电源

- 采集卡 UVC／UAC 枚举、权限、格式、拔插恢复；黑画面不能直接等同于无信号。
- 启动或网络失效进入 Rescue Lock，LCD 亮屏等待；HDMI 无帧、NO SIGNAL、黑屏及反复协商均不得自动关屏。
- 只有已认证且持续推进的实际画面连续两秒才接管网络；心跳或仅连接不能解除救援状态。
- 已配对 Sender 人工关屏／唤回仅控制 LCD，监听、存储及媒体服务继续运行；失败、超时、迟到结果安全恢复。
- 人工关屏状态在断线时保持，显示服务重启恢复亮屏等待。Sender 睡眠/唤醒联动已实现，按 [睡眠联动验收](SenderSleepSync-2026-10-08.md) 验证实际息屏、长时间睡眠后重连与手动选择保留；离线本地物理控制仍待开发。
- Sender 崩溃／重启、拔线、更新、FileVault／Recovery 场景分别验收；共用 iMac 系统及供电的限制必须记录。

## 独立服务与完整卸载

- 无视频会话时 Storage Watcher 仍推送只读卷快照；验证 SDXC／USB 插拔、独立崩溃恢复和显式 SMB 共享／账户挂载，不自动授予文件访问权限。
- 摄像头／麦克风为 iMac → Sender，按请求采集，权限拒绝、关闭请求和重连均停止旧采集。正式签名、虚拟设备激活及常用通话应用兼容单独验收。
- 两端完整卸载删除应用、启动项、凭据、UUID、配对文件、设置、缓存和日志；保留用户存储文件及物理摄像头／麦克风。

构建与无硬件回归见 [测试文档](Testing.md)。每次验收记录包校验值、机器／系统、场景、结果与未通过项，更新兼容性表。
