# Alpha scope / Alpha 使用范围

This is an Alpha development preview for direct Thunderbolt or Gigabit Ethernet connections. The current implementation does not require pairing codes and does not provide transport encryption. macOS continues to manage screen recording, input, camera, and microphone permissions.

If this repository offers GitHub private vulnerability reporting, use that channel for sensitive reports. Otherwise, open an issue asking for a private contact method without publishing credentials, personal data, or exploit details. The upstream project's contact address is not this fork's support channel.

本项目为雷电或千兆有线直连的 Alpha 开发预览，当前不要求配对码，也不提供链路加密。录屏、输入、摄像头和麦克风权限仍由 macOS 管理。

如本仓库已开启 GitHub 私密漏洞报告，请使用该入口；否则先通过 Issue 请求私密联系方式，不公开凭据、个人信息或利用细节。上游项目联系方式不作为本分支支持渠道。
